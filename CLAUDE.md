# The 2026 Iran War: A Geoeconomic Autopsy

A long-form editorial data-journalism piece for the Stepwell Centre for Asian
Futures, Ahmedabad University. Static site: `index.html`, `css/styles.css`,
`js/app.js`, `js/data.js`. Libraries: Leaflet, Chart.js, D3 (d3-sankey).

## Design System
Always read `DESIGN.md` before making any visual or UI decisions.
All font choices, colors, spacing, and aesthetic direction are defined there.
Do not deviate without explicit user approval.
In QA mode, flag any code that doesn't match `DESIGN.md`.

The site is being overhauled from a dark "data terminal" theme to a light,
NYT-style editorial "document of record." See `CHANGELOG.md` for the approach
and the step-by-step plan.
